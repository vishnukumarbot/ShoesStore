# ShoeStore App

**Developed by Vishnu Gelle**
**Student ID:11906455**

**A modern Android application built using Kotlin and MVC architecture for exploring, selecting, and purchasing shoes.**

---

## Application Features

- **Home Screen**: Browse different shoe companies with their prices.
- **Detail Screen**: Select shoe colors dynamically; image updates based on color.
- **Cart Screen**: Add shoes to cart and view the total price.
- **Dynamic UI**: Material Design components for clean look.
- **MVC Architecture**: Clean separation of concerns.
- **Navigation Component** for smooth multi-screen transitions.
- **Image Loading with Glide** for efficient and modern loading.
- **Device Compatibility**: Works across various Android versions.

---

## Built With

- Language: Kotlin
- Architecture: MVC (Model-View-Controller)
- UI: ConstraintLayout, RecyclerView, BottomNavigationView
- Image Loading: Glide
- Minimum SDK: 24+
- Target SDK: 34

---

## How to Build

1. Clone or download the project.
2. Open in **Android Studio**.
3. Build the project.
4. Run on an emulator or physical device (min SDK 24+).
5. No need of any setup like to set a server, getting API keys.
